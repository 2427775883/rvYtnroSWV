# 项目简介

## 核心功能
- 前后端分离架构，实现数据交互
- 基于 Python Flask 框架构建后端
- 使用 MySQL 作为数据存储
- 自动化财务分析
- 智能分析收支记录
- 直观图表展示数据趋势和分类统计

## 适用场景
- 个人财务管理
- 财务状况分析
- 数据可视化展示

## 技术特点
- 使用 Flask 框架简化开发流程
- MySQL 提供稳定的数据存储方案
- Bootstrap 5 确保界面美观
- Chart.js 提供丰富的图表展示功能
